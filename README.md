# kotlin-lotto-precourse
## 구현할 기능
### 1. 입출력
**입력**
- 로또 구입 금액을 입력받는다.
- 당첨 번호를 입력받는다. 번호는 쉼표(,)를 기준으로 구분한다.
- 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 에러 메서지를 출력 후 그 부분부터 입력을 다시 받는다.
- 보너스 번호를 입력받는다.

**입력 확인**
- 입력된 구입 금액 값을 확인한다.
  - 정수형인지 확인한다.
  - 1,000원 단위로 구입되었는지 확인한다.
- 입력된 당첨번호를 확인한다. 
  - 번호가 정수형인지 확인한다.
  - 번호는 1에서 45 사이인지 확인한다.
  - 번호가 6개 인지 확인한다.
  - `,`를 기준으로 구분한다.
- 입력된 보너스 번호를 확인한다.
  - 정수형인지 확인한다.
  - 1에서 45 사이인지 확인한다.

**출력**
- 위의 실행 결과 예시와 같이 가이드와 결과를 출력한다.
- 당첨 통계를 출력한다.
- 총 수익률을 출력한다.

### 2. 로또 생성
- 로또를 규칙에 맞게 입력한 구입비 대로 생성한다.
- 로또 하나는 중복되지 않는 6개의 숫자를 뽑는다.
- 로또는 하나에 1000원이다.
- 생성된 로또들의 번호들은 정렬된다

### 3. 횟수 계산
- 입력된 구매값을 로또 개수로 반환해준다.

### 4. 숫자 생성
**랜덤 숫자 생성**
- 1 ~ 45의 숫자들을 랜덤으로 생성한다.

### 5. 로또 확인
- 로또 번호 개수가 겹치는 값 없이 6개인지 확인한다.
- 당첨 번호와 비교해 몇 개가 겹치는지 확인한다.
- 등수를 가린다. 당첨은 1등부터 5등까지 있다.
  - 모두 맞추면 1등이다.
  - 5개를 맞추고 보너스 번호를 맞추면 2등이다.
  - 5개를 맞추고 보너스 번호를 못 맞추면 3등이다.
  - 4개를 맞추면 4등이다.
  - 3개를 맞추면 5등이다.

### 6. 당첨 금액 계산
- 로또를 산 금액과 당첨 통계를 계산해 수익률을 계산한다.
  - 수익률은 소수점 둘째 자리에서 반올림한다.
