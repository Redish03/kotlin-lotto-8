# kotlin-lotto-precourse
## 구현할 기능
### 입출력
**입력**
- 로또 구입 금액을 입력받는다.
- 당첨 번호를 입력받는다. 번호는 쉼표(,)를 기준으로 구분한다.
- 보너스 번호를 입력받는다.

**입력 확인**
- 입력된 구입 금액 값을 확인한다.
  - 정수형인지 확인한다.
  - 1,000원 단위로 구입되었는지 확인한다.
- 입력된 당첨번호를 확인한다. 
  - 번호가 정수형인지 확인한다.
  - 번호는 1에서 45 사이인지 확인한다.
  - 번호가 6개 인지 확인한다.
- 입력된 보너스 번호를 확인한다.
  - 정수형인지 확인한다.
  - 1에서 45 사이인지 확인한다.

### 숫자 생성
**랜덤 숫자 생성**
- 1 ~ 45의 숫자들을 랜덤으로 생성한다.
