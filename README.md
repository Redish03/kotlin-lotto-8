# kotlin-lotto-precourse
## 구현할 기능
### 입출력
**입력**
- 로또 구입 금액을 입력받는다.
- 당첨 번호를 입력받는다. 번호는 쉼표(,)를 기준으로 구분한다.
- 보너스 번호를 입력받는다.

**입력 확인**
- 입력된 구입 금액 값을 확인한다.
  - 정수형인지 확인한다.
  - 1,000원 단위로 구입되었는지 확인한다.
- 입력된 당첨번호를 확인한다. 
  - 번호가 정수형인지 확인한다.
  - 번호는 1에서 45 사이인지 확인한다.
  - 번호가 6개 인지 확인한다.
- 입력된 보너스 번호를 확인한다.
  - 정수형인지 확인한다.
  - 1에서 45 사이인지 확인한다.

**출력**
- 위의 실행 결과 예시와 같이 가이드와 결과를 출력한다.
- 당첨 통계를 출력한다.
- 총 수익률을 출력한다.

### 로또 생성
- 로또를 위의 규칙에 맞게 입력한 구입비 대로 생성한다.

### 횟수 계산
- 입력된 구매값을 로또 개수로 반환해준다.

### 숫자 생성
**랜덤 숫자 생성**
- 1 ~ 45의 숫자들을 랜덤으로 생성한다.

### 로또
- 로또 번호 개수가 겹치는 값 없이 6개인지 확인한다.
- 정답 번호와 비교해 몇 개가 겹치는지 확인한다.

### 당첨 금액 계산
- 로또를 산 금액과 당첨 통계를 계산해 수익률을 계산한다.
